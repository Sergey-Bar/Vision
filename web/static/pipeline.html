    The state machine, in its own words

    The verification state machine is golden-tested: fixture → canonical → verification → incident, byte-stable.

    A decision with no observation is a question, not a claim. The AI plane was never asked, so the incident is raised as a query severity for an operator, carries decidedWithoutAiObservation: true, and its observation row says degraded with the reason. It is never rendered as “nothing was found” — that rendering is the one failure this product must never commit.
    What is NOT RUN here. Detection accuracy on the relay footage: the pinned model is a multi-scale anchored export and the in-process decoder refuses it by name; the sidecar decodes it, and nobody has measured accuracy on that footage.
