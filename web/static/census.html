Census — every capability, one table, honest grades

One row per capability this repository actually has, each carrying the command that proves it or the file it was measured into. The grades are the point: Live can be run from this showcase now; Recorded is a dated artefact or measurement on this machine; NOT RUN is a capability that exists and was deliberately not exercised, with the reason in the row; Lab is a Python tool outside the gate path. Nothing is graded "done" here — that word would be a claim with no file behind it.
