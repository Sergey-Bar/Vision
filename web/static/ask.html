Ask it in plain words. It answers from the record, or it refuses.

One input. A sentence enters it and what comes out is a reading of a file this machine already wrote, or a rule drafted in the product’s own language and compiled by its own compiler, or a refusal said plainly. The words go nowhere else: they select an intent, they never reach a shell, a path, a database or a model. A refused sentence is not a failure — it is the second sentence this page knows how to print.

try: show me the last detection · make a rule for someone running on the fence at night · is the ledger intact · cameras · brief me · how many runs
How to read “no model needed”. The control behind that claim (red-check RC-30 and friends) is built so the ask page answers with nothing more than stored facts, the POC’s own tool and the repository’s own rule compiler. Attaching a model later only changes what is narrated, never what is found: the sentence, the draft and the verdict are written before it speaks.
